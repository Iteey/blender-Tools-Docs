# Missing lightmap UV

## Что проверяет

Не найден ожидаемый lightmap UV-канал.

## Как работает проверка

Проверяет существование выбранного UV-канала при включённой проверке lightmap.

## Почему важно для UE5

Запечённое освещение может работать некорректно, если проект требует lightmap UV.

## Как исправить

Создай подходящий UV-канал или отключи проверку при полностью динамическом освещении.

**Шаги и сочетания клавиш (стандартная раскладка Blender):**

1. В **Object Data Properties → UV Maps** нажми **+**, чтобы создать отдельную UV-карту для световых карт.
2. Перейди в **Edit Mode**, выдели грани (`A`) и создай уникальную развёртку через `U` → **Smart UV Project** или **Unwrap**.
3. В UE5 проверь индекс Lightmap Coordinate и возможность генерации lightmap UV при импорте. При полностью динамическом освещении отдельный канал может не требоваться.

## Важные нюансы

По умолчанию lightmap-аудит отключён; полностью динамическое освещение может не требовать канала.
