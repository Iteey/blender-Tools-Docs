# Inconsistent face winding

## Что проверяет

Соседние грани используют общее ребро в одном направлении.

## Как работает проверка

На рёбрах с двумя соседними гранями сравнивает направление обхода общего ребра.

## Почему важно для UE5

Такие участки могут иметь несогласованные нормали и некорректный backface culling.

## Как исправить

Выдели грани, проверь Face Orientation; для обычной цельной оболочки попробуй Shift+N (Recalculate Outside).

**Шаги и сочетания клавиш (стандартная раскладка Blender):**

1. В **Edit Mode** (`Tab`) включи **Face Orientation** через **Viewport Overlays**.
2. Для обычной замкнутой оболочки выдели нужную геометрию и нажми `Shift + N` (**Recalculate Outside**).
3. Если отдельная грань ориентирована неверно, выдели только её и нажми `Alt + N` → **Flip**.
4. Повтори сканирование: `Shift + N` может не дать однозначного результата на открытых или не-манифолдных участках.

## Важные нюансы

Целиком перевёрнутая замкнутая оболочка может пройти эту проверку — см. Inverted Normals.
