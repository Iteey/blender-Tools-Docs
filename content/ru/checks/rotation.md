# Unapplied Rotation

## Что проверяет

У объекта есть неприменённый Rotation.

## Как работает проверка

Проверяет отклонение вращения от нулевого с учётом режима вращения объекта.

## Почему важно для UE5

Ориентация при импорте может отличаться от ожидаемой настройками проекта.

## Как исправить

Если нужно: Object Mode > Ctrl+A > Rotation. Не применяй бездумно к ригам и привязанным объектам.

**Шаги и сочетания клавиш (стандартная раскладка Blender):**

1. В **Object Mode** выдели объект и нажми `Ctrl + A` → **Rotation**.
2. Убедись, что ориентация объекта, риг и дочерние объекты остались правильными.
3. Применение Rotation необязательно для каждого Static Mesh — действуй по требованиям пайплайна.
