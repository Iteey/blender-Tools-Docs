# Missing external textures

## Что проверяет

Некоторые внешние файлы изображений не найдены.

## Как работает проверка

Проверяет существование внешних файлов FILE-изображений; packed ресурсы исключаются.

## Почему важно для UE5

Материал может потерять текстуры при переносе проекта.

## Как исправить

Исправь путь к изображениям или упакуй их через File > External Data > Pack Resources.

**Шаги и сочетания клавиш (стандартная раскладка Blender):**

1. В **Shader Editor** выбери нужный узел **Image Texture** и укажи правильный файл через **Open**.
2. Если изображения уже найдены, для переноса проекта используй **File → External Data → Pack Resources**.
3. Для диагностики путей открой `F3` и поищи **Find Missing Files** (если доступно в текущей версии/контексте). Упаковка сама по себе не восстанавливает отсутствующий файл.

## Важные нюансы

Тайловые UDIM-пути здесь не распознаются специальным образом, поэтому возможны ложные срабатывания.
