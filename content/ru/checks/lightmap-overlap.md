# Lightmap UV overlap

## Что проверяет

Lightmap UV-острова перекрываются.

## Как работает проверка

На выбранном lightmap UV ищет пересечение UV-треугольников; действует лимит анализа.

## Почему важно для UE5

В запечённом освещении это может вызвать световые артефакты.

## Как исправить

Раздели перекрывающиеся UV-острова с достаточными отступами.

## Важные нюансы

Не учитывает толщину padding по разрешению lightmap. Есть ограничение размера проверки.
