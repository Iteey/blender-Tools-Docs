# Missing lightmap UV

## Что проверяет

Не найден ожидаемый lightmap UV-канал.

## Как работает проверка

Проверяет существование выбранного UV-канала при включённой проверке lightmap.

## Почему важно для UE5

Запечённое освещение может работать некорректно, если проект требует lightmap UV.

## Как исправить

Создай подходящий UV-канал или отключи проверку при полностью динамическом освещении.

## Важные нюансы

По умолчанию lightmap-аудит отключён; полностью динамическое освещение может не требовать канала.
