# Inverted normals (closed shells)

## Что проверяет

Замкнутая внешняя оболочка имеет отрицательный ориентированный объём — вероятно, все её грани направлены внутрь.

## Как работает проверка

Анализирует замкнутые оболочки с помощью ориентированного объёма. Открытые и вложенные оболочки требуют осторожности.

## Почему важно для UE5

В UE5 может быть видна обратная сторона поверхности, а лицевая — отсекаться.

## Как исправить

Нажми на название проверки, чтобы выделить грани. В Edit Mode включи Face Orientation и проверь. Для обычной оболочки: Shift+N. Для полостей и особой геометрии сначала оцени вручную.

## Важные нюансы

Для открытой сетки, внутренних полостей и вложенных оболочек алгоритм может не определить «наружу». Отрицательный Scale проверяется отдельно.
