# Empty mesh

## Что проверяет

В объекте нет полигонов.

## Как работает проверка

Проверяет, что у исходной сетки есть полигоны.

## Почему важно для UE5

Пустому Static Mesh нечего отображать в UE5.

## Как исправить

Проверь объект в Edit Mode; создай или восстанови нужную геометрию.

**Шаги и сочетания клавиш (стандартная раскладка Blender):**

1. Выбери объект и нажми `Tab` для перехода в **Edit Mode**. Проверь, есть ли вершины и грани.
2. Если геометрия потеряна, восстанови её через `Ctrl + Z` (если действие ещё можно отменить) или импортируй нужный меш заново.
3. Для создания новой геометрии используй `Shift + A` (**Add**) в Edit Mode. Не добавляй случайную геометрию только ради прохождения проверки.
