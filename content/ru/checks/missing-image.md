# Empty image nodes

## Что проверяет

У некоторых Image Texture nodes не назначено изображение.

## Как работает проверка

Ищет Image Texture nodes без назначенного изображения.

## Почему важно для UE5

Материал может отобразиться не так, как задумано.

## Как исправить

Открой Shader Editor и назначь изображение либо удали ненужный узел.
